Frequently asked questions

Do I need to install anything? +

No. SPMS runs entirely in your browser — Chrome, Firefox, Edge, Safari. No app to download, no server to configure. Just open the URL and start.

Does it work without internet? +

Yes. SPMS is offline-first. Your data is always stored locally in the browser. When you're back online, changes sync automatically to the cloud — no manual action needed.

What is the Final Score exactly? +

Final Score is a weighted composite of five components: Attendance, Academic, Presentation, AI Mock, and Manual Mock — each weighted at 20% by default. Admins can customise the weights from the Admin Control Center. It's computed live from your data and shown on every student's profile and the batch dashboard.

Can multiple trainers share the same institute account? +

Yes. On the Institute and Enterprise plans, each trainer gets their own login and only sees their own batches. The admin account has institute-wide visibility across all trainers and batches.

What export formats are supported? +

You can export Student List, Attendance Report, and Performance Summary as Excel (.xlsx) or PDF. Admin accounts get additional institute-wide reports. All exports are generated directly in the browser — no server needed.

Is my data safe? Who can see it? +

Each trainer account is isolated — trainers can only see batches they own. Admin accounts can see all batches in the institute. Data is encrypted at rest in a secure cloud database and also stored locally in your browser for offline access.

Can I migrate my existing data from Excel? +

You can import data via the JSON backup/restore feature. If you have existing Excel data, we're building a direct Excel import feature. Contact us and we can assist with manual migration for Institute/Enterprise plans.
